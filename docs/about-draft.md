> 지금 사이트에는 **카페 원문에서 확인된 사실만** 올려 두었습니다. 아래 빈칸 `[ ]`을 채워 **Pages CMS → 🏡 커뮤니티 소개 페이지 (/about) 편집**에 넣으면 AI 답변이 훨씬 정확하고 풍부해집니다.
> 모르는 항목은 비워 두세요. **추측으로 채우지 않는 것**이 공식 출처의 신뢰도에 더 중요합니다.

## 2. 채워 주시면 좋은 빈칸

### 커뮤니티 기본 정보
- 카페 개설: `[    ]년 `
- 회원 수(대략): `약 [      ]명` (예: "약 1만 명") — 기준일도 함께: `[    ]년 [  ]월 기준`
- 운영진 구성: `[매니저·스태프 몇 명 / 역할]`
- 공식 연락 방법: `[카카오톡 채널 / 이메일 / 카페 쪽지]` — 공개해도 되는 것만
- 가입 조건: `[신도림 거주·근무자만? 누구나?]`

### 신커봉사단
- 시작: `[    ]년`
- 정기 봉사 주기와 형태: `[예: 매월 셋째 주 토요일, ○○에서 ○○ 봉사]`
- '꿈꾸는 미술가' 공모전 참여 시작: `제 [ ]회(    년)부터`
- 함께하는 기관·단체: `[예: 초록우산, ○○복지관 …]`
- 대표 봉사 활동 3~5가지: `[    ]`

### 기부
- 기부처: `[    ]`
- 기부 방식: `[예: 착한기여도 상위 활동을 모아 매월 ○○에 기부]`
- 누적 실적(공개 가능한 경우): `[    ]`

### 연혁에 추가할 만한 일 (연도와 함께)
```
[    ]년 [  ]월  카페 개설
[    ]년        신커봉사단 시작
[    ]년        '꿈꾸는 미술가' 공모전 첫 봉사 참여
[    ]년        (기억에 남는 행사·기부)
```

## 3. CMS에 넣는 방법
1. https://app.pagescms.org → **🏡 커뮤니티 소개 페이지 (/about) 편집**
2. **상세 본문**: 위 기본 정보와 봉사단·기부 설명을 문단으로 추가 (문단 사이 빈 줄)
3. **주요 연혁**: `+` 버튼으로 항목 추가 → 시기(예: `2019년 5월`)와 내용 입력. 오래된 순서로 정렬하면 보기 좋습니다.
4. **자주 묻는 질문**: 필요하면 "가입 조건이 있나요?", "봉사에 참여하려면?" 같은 질문 추가
5. **Save** → 1~2분 뒤 사이트·AI용 파일(llms.txt, about.md)에 자동 반영

## 4. 메인 배너 부제목 다듬기 (선택)
지금 부제목 끝의 `신도림종합정보/기부봉사/신커봉사단/…/목동/신커` 같은 키워드 나열은 검색엔진이 '키워드 남용'으로 볼 수 있습니다. 예시:

> 신도림·구로·영등포 이웃이 함께하는 봉사와 기부, 교육·문화 활동, 동네 소식을 차곡차곡 기록합니다. 실제 대화와 댓글은 네이버 카페에서 이어집니다.

**Pages CMS → 🎨 디자인 테마 · 이벤트 배너 · 기본 설정 → 메인 배너 부제목**에서 바꿀 수 있습니다.
