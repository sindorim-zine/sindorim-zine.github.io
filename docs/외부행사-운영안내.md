# 🔎 외부 행사 소식 운영 안내

> **목표:** 신도림은 1·2호선이 만나는 교통의 요지라, 서울·수도권은 물론 전국 행사에 다녀오기 좋습니다.
> 회원들이 다녀와서 후기만 남기는 대신, **미리 알려 드리고 가는 것은 회원이 고르도록** 합니다.
> 신커가 주최하지 않는 행사라는 점을 사이트에 분명히 표시합니다.

---

## 1. 어떻게 돌아가나요?

```
매일 아침 8시 ─▶ 공공 API에서 30일 안에 시작하는 행사를 하루 최대 12건 수집
                 (서울시 문화행사 · 전국 축제 · 공공기관 체험 예약 · 공연)
운영진 제보   ─▶ CMS에 공식 안내 주소 + 안내문 붙여넣기
                        │
                        ▼
        AI가 제목·3줄 요약·일정·장소·요금 정리 + 광고성 참고 표시(🟢🟡🔴)
                        │
                        ▼
   🧑 운영진 판단 (Pages CMS → 🔎 외부 행사 후보 검토 · 제보)
      ✅ 공개  → 1~2분 뒤 '가볼 만한 행사'에 "외부 행사 · 신커 주최 아님" 표시와 함께 발행
      🚫 제외  → 삭제, 같은 행사는 다시 수집하지 않음
      ⏳ 대기  → 행사가 끝나면 자동 정리
```

- **AI는 공개하지 않습니다.** 정리와 광고성 표시만 하고, 공개는 항상 운영진이 정합니다.
- 검토 대기가 40건 넘게 쌓이면 자동 수집을 쉽니다. 운영진이 정리하면 다시 수집합니다.

## 2. 공개 / 제외 판단 기준 (예시)

| ✅ 공개하면 좋은 것 | 🚫 제외할 것 |
|---|---|
| 지자체·공공기관·문화재단 축제, 무료 공연·전시 | 분양·보험·대출·투자·학원 상담 유도 |
| 공공기관 체험·교육 프로그램 모집 | 회원가입·앱 설치가 조건인 경품 행사 |
| 누구나 구경할 수 있는 브랜드 팝업스토어(🟡) | 체험단을 빙자한 리뷰 마케팅, 유료 클래스 모객 |
| 신도림에서 대중교통으로 다녀오기 좋은 행사 | 너무 비싸거나 회원 관심과 거리가 먼 행사 |

AI 표시는 참고용입니다: 🟢 공공·비영리 · 🟡 상업적이지만 누구나 참여 · 🔴 판매·가입·상담 유도

## 3. 운영진 제보하는 법 (팝업스토어·브랜드 행사 등)

1. 아래 **4. 정보 찾는 곳**에서 행사를 찾습니다.
2. Pages CMS → **🔎 외부 행사 후보 검토 · 제보** → **새로 만들기**
3. **② 공식 안내 주소**에 주최 측 공식 페이지 주소, **③ 안내 내용**에 공식 안내문(일정·장소·요금·신청 방법)을 붙여 넣고 **⏳ 검토 대기**로 저장
4. 1~2분 뒤 AI가 정리해 둔 내용을 확인 → **✅ 공개**로 바꿔 저장

> 개인 블로그·SNS 후기보다 **주최 측 공식 안내**를 넣어 주세요. 포스터 사진은 허락 없이 쓰면 저작권 문제가 될 수 있어 비워 두는 것을 권합니다(기본 일러스트가 나옵니다).

## 5. 자동 수집을 켜려면 — API 키 등록 (최초 1회)

키를 하나도 등록하지 않아도 **운영진 제보는 지금 바로 쓸 수 있습니다.** 키를 등록한 출처만 자동 수집합니다.

| GitHub Secret 이름 | 발급처 | 수집하는 것 |
|---|---|---|
| `SEOUL_API_KEY` | 서울 열린데이터광장 https://data.seoul.go.kr → 로그인 → 인증키 신청(일반 인증키) | 서울시 문화행사 정보 + 서울시 공공서비스예약(문화체험) |
| `TOUR_API_KEY` | 공공데이터포털 https://www.data.go.kr → '한국관광공사_국문 관광정보 서비스_GW' 활용신청 | 전국 행사·축제 |
| `KOPIS_API_KEY` (선택, 지금은 등록 안 함) | 공연예술통합전산망 https://www.kopis.or.kr — 공연업계 관계자 위주로 가입을 받아 일반 단체는 발급이 어려울 수 있음 | 서울·경기 공연 예정작 |

등록 위치: GitHub 저장소 → **Settings → Secrets and variables → Actions → New repository secret**
등록 후 **Actions → Publish & Deploy → Run workflow**를 누르면 바로 한 번 수집합니다.

- 공공데이터포털 키는 개발계정이 자동 승인되며 하루 1,000회까지 쓸 수 있습니다(이 사이트는 하루 수십 회만 씀).
- 공연(KOPIS) 키는 없어도 됩니다. **서울시 문화행사 정보에 콘서트·클래식·뮤지컬·연극·국악 공연이 이미 들어 있어** 서울 공연 소식은 `SEOUL_API_KEY`만으로 받습니다. KOPIS 키는 나중에 발급받으면 등록만 하면 되고(하루 1건 정도만 섞임), 없으면 자동으로 건너뜁니다.

## 6. 출처 표시 (이용 조건)

- 서울 열린데이터광장 자료는 **공공누리 제1유형(출처 표시)** 입니다. 공개된 글의 '정보 출처'에 자동으로 표시됩니다.
- 한국관광공사·KOPIS 자료도 '정보 출처'에 기관 이름이 자동으로 들어갑니다.
- 다른 사이트의 화면을 긁어 오지(스크래핑) 않고, 공식 공개 데이터와 운영진 제보만 사용합니다.
